What is AI MEET
AI MEET is a desktop application that helps the user to record audio of online meetings, later it transcribe the audio and summarized it with key points and action items for boosting productivity.
Who Can Use This App
Students, Freelancers, Employees and those who have to attend long online meetings and struggle to write notes and listen to the speaker at the same time, can use this tool to automate most of their workload.
How to Use This App
Install on your computer -> Get a free Gemini API Key from Google AI Studio and use it in the app -> Start the app -> Give a name of the meeting and press "Start Recording" -> Start your meeting, the app is continuously recording the system audio -> After the meeting, press "Stop Recording" -> Rest of the task will be done by the app.
What are The Requirments
You need a Windows 10/11 (x64 Bit) computer, a Gemini API Key and a decent internet connection to use the app.
How to Get The App
Press on "Download For Windows" and install the app for free.
